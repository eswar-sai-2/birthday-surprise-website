# 🎉 Birthday Surprise Website

A beautiful and interactive Birthday Surprise Website built using **HTML, CSS, and JavaScript**. This project creates a memorable birthday experience with animations, music, photos, a countdown, a heartfelt letter, and a celebration sequence.

## ✨ Features

- 🎁 Gift Box Opening Animation
- ⏳ Birthday Countdown
- 🎂 Date of Birth Verification
- 🎉 Happy Birthday Celebration
- 📷 Childhood Memory Photo
- 🖼️ Recent Photo Display
- 💌 Personalized Birthday Letter
- 🎂 Birthday Cake Animation
- 🎆 Fireworks Celebration
- 🎵 Background Birthday Music
- ❤️ Floating Heart Animations
- 🔄 Replay Option
- 📱 Responsive Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)

## 🚀 How to Run

1. Clone the repository:

```bash
git clone https://github.com/eswar-sai-2/birthday-surprise-website.git
```

2. Open the project folder.

3. Open `index.html` in your browser.

Or deploy it using platforms like:

- Netlify
- GitHub Pages
- Vercel
